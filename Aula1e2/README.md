# Lista de Exercícios - Linguagem Kotlin

Projeto desenvolvido para praticar conceitos básicos da linguagem Kotlin por meio de exercícios de entrada, processamento e saída de dados.

## Descrição

O projeto contém cinco exercícios propostos no material de introdução ao Kotlin, além de um menu interativo para selecionar e executar cada atividade.

Os exercícios trabalham entrada de dados, conversão de tipos, operações matemáticas, estruturas condicionais e manipulação de textos.

## Exercícios

### 1. Maiúsculas e minúsculas

Solicita uma palavra e exibe o texto em letras maiúsculas e minúsculas.

### 2. Soma de dois números

Solicita dois números inteiros e calcula a soma. O programa também verifica entradas inválidas.

### 3. Número par ou ímpar

Solicita um número inteiro e verifica se ele é par ou ímpar utilizando o operador `%`.

### 4. Média das notas

Solicita três notas, calcula a média e informa a situação do aluno:

* Média ≥ 6: Aprovado
* Média ≥ 4: Recuperação
* Média < 4: Reprovado

### 5. Conversor de temperatura

Solicita uma temperatura em Celsius e permite convertê-la para:

* Fahrenheit
* Kelvin

## Menu

O programa possui um menu interativo:

```text
1 - Maiúsculas e minúsculas
2 - Soma de dois números
3 - Par ou ímpar
4 - Média das notas
5 - Conversor de temperatura
0 - Sair
```

O usuário pode executar os exercícios quantas vezes quiser e utilizar a opção `0` para encerrar o programa.

## Tecnologias utilizadas

* Kotlin
* IntelliJ IDEA
* JVM
* Entrada de dados com `readln()`

## Conceitos praticados

* `var` e `val`
* Tipos `Int`, `Double` e `String`
* Entrada e conversão de dados
* `toIntOrNull()` e `toDoubleOrNull()`
* Tratamento de entradas inválidas
* Operações matemáticas
* Operador `%`
* `if` e `else`
* `when`
* `while`
* Interpolação de strings
* `uppercase()` e `lowercase()`
* Formatação de números decimais

## Como executar

1. Abra o projeto no IntelliJ IDEA.
2. Abra o arquivo que contém a função `main()`.
3. Execute o programa.
4. Escolha uma opção no menu apresentado no terminal.
